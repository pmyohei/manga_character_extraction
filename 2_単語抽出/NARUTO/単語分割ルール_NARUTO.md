# 単語分割ルール（NARUTO）

共通ルールは `2_単語抽出/単語分割ルール_共通.md`。ここには NARUTO 固有の
確定済み判断だけを記録する。同種の語が出たら再質問せずこのとおり処理する。

（1巻1話のユーザー確認で確定）

## 称号・呼称

- `火影` ＝ 1語（`火影様` → 様を外し `火影`、`火影様たち` → `火影`）
- `四代目火影` → `四代目` `火影` ／ `初代火影` → `初代` `火影` ／ `歴代火影` → `歴代` `火影`
- `三代目`（呼びかけ）＝ 1語 ／ `先代` ＝ 1語
  - ※ `四代目` `三代目` のように「数字＋代目」は**分割せず1語**にする（称号扱い）。
- `うずまきナルト` ＝ 1語（本文で「うずまき ナルト」と分かち書きされていても1語で記録）。
  姓名のうち `ナルト` だけが出ていれば `ナルト`。
- `イルカ先生` `ミズキ先生` → 名前と `先生` を各1語（`先生` は名詞として残す）
- `ナルト君` → `君` は接尾辞で外し `ナルト`

## 妖狐まわり

- `妖狐` ＝ 1語 ／ `狐` ＝ 1語 ／ `バケ狐` ＝ 1語
- `九尾` ＝ 1語 ／ `九尾狐` ＝ 1語
- `九尾の妖狐` → `九尾` `妖狐`（「〜の〜」型）
- `九つの尾` → `九つ` `尾`（数量表現）

## 里・忍

- `木の葉` `木ノ葉隠れ` ＝ 各1語（地名扱い）
- `木の葉の額あて` → `木の葉` `額あて` ／ `木ノ葉隠れの里` → `木ノ葉隠れ` `里`
- `忍の里` → `忍` `里` ／ `忍の者` → `忍` `者`
- `忍者` ＝ 1語 ／ `忍` ＝ 1語 ／ `忍術` ＝ 1語 ／ `額あて` ＝ 1語
- `忍者学校` → `忍者` `学校`

## 術・巻物

- `変化の術` → `変化` `術` ／ `おいろけの術` → `おいろけ` `術` ／ `分身の術` → `分身` `術` ／
  `影分身の術` → `影分身` `術`
- `影分身` ＝ 1語 ／ `多重影分身` ＝ 1語
- `高等忍術` → `高等` `忍術` ／ `禁じ手` ＝ 1語（`禁じ手の忍術` → `禁じ手` `忍術`）
- `封印の書` → `封印` `書` ／ `封印の書物` → `封印` `書物` ／ `巻物` ＝ 1語

## その他の複合語

- `卒業試験` → `卒業` `試験` ／ `卒業祝い` → `卒業` `祝い` ／ `復習テスト` → `復習` `テスト`
- `授業中` → `授業` `中`
- `顔岩` ＝ 1語 ／ `山崩れ` ＝ 1語 ／ `半日` ＝ 1語 ／ `ラーメン屋` ＝ 1語
- `存在価値` → `存在` `価値`
- `一人前` ＝ 1語 ／ `足手まとい` ＝ 1語 ／ `両親` ＝ 1語 ／ `心変わり` ＝ 1語 ／ `手の内` ＝ 1語
- `親の愛情` → `親` `愛情` ／ `親の仇` → `親` `仇` ／ `人の心の苦しみ` → `人` `心` `苦しみ`
- `鼻血ブー` → `鼻血`（`ブー` は書き文字の擬音で除外）

## 数量

- `12年前` → `12` `年` `前` ／ `千倍` → `千` `倍` ／ `千人` → `千` `人`
- `術一個` → `術` `一` `個` ／ `一発` → `一` `発` ／ `三度目` ＝ 1語（序数）
- `万に一つ` → `万` `一つ`
