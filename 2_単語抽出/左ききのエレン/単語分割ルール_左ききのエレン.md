# 単語分割ルール（左ききのエレン）

共通ルールは `2_単語抽出/単語分割ルール_共通.md`。ここには左ききのエレン固有の
確定済み判断だけを記録する。同種の語が出たら再質問せずこのとおり処理する。

（1巻1話のユーザー確認・作業判断で確定）

## 数量（共通ルールの拡張）

- 算用数字＋位取り語（億・万）は**数字＋位取り語を1語**、助数詞は別語にする
  （ユーザー確認済み）。
  - 例: `3億円` → `3億` `円` ／ `3億!!` → `3億` ／ `10万人` → `10万` `人`
- `4年目`のように「数字＋年＋目」の順序表現は共通ルールの「〜代目・〜度目」に準じ
  **分割せず1語**にする。
- `2・3回`型ではない単純な「数字＋年」「数字＋分」等は共通ルールどおり数字と助数詞を分ける
  （例: `10年前` → `10` `年` `前`）。

## 固有名詞・複合語

- 会社名の匿名表記 `S社` は分割せず1語（`S` と `社` に分けない）。
- `目黒広告社` `広告代理店` `クリエイティブ部門` `広告代理店` は各1語の複合語として扱う。
- `AM10:00` のような時刻表記は1語のまま。
- 役職略称 `AD` `CD` `D` は各1語（分割対象なし）。
- 人名 `朝倉光一` `箭内道彦` はフルネームで1語。ニックネーム `みっちゃん` は
  接尾辞処理せず1語のまま（`さん` `くん` 等の一般的な接尾辞とは別扱い）。
- `幽霊部員` `自信っぷり` `未来予想図` `デザイナー雑誌` `グラフィティアート`
  `グラフィティアーティスト` `グラビアアイドル` は各1語の複合語。
- 作品タイトルの由来語 `左きき` は1語（分割しない）。

## 形式名詞の扱い（共通ルールの適用確認）

- `オレの事` `そいつのこと` `〜ということ` の `事／こと` は共通ルールの形式名詞に該当し
  **除外する**（具体的な事物を指すように見えても、「〜について」の意の軽い名詞化用法は除外）。
- `曲がった所` のような場所を指すように見える `所` も、共通ルールの形式名詞リストに
  明示されているため**除外する**（`場所` は別語として抽出対象）。

## その他

- カタカナ強調代名詞 `コレ` `ヤツ` は本文表記のまま抽出（`これ` `やつ` に正規化しない）。
- `こんなん`（＝「こんなの」のくだけた形）は指示語として1語で抽出する。
- `あっこ`（文脈上「あそこ／あ、ここ」相当の口語表現）は指示語として1語で抽出する。
- `いつもの〜` の `いつも` は名詞的（連体）用法として抽出する。
