# 単語分割ルール（ジョジョの奇妙な冒険）

共通ルールは `2_単語抽出/単語分割ルール_共通.md`。ここにはジョジョの奇妙な冒険固有の
確定済み判断だけを記録する。同種の語が出たら再質問せずこのとおり処理する。

## 複合名詞（1語のまま扱う）

`石仮面` / `返り血` / `生き血` / `骨串` / `人肉喰い` / `メキシコ中央高原` / `ジョースター家` /
`ひとり息子` / `女の子` / `男の子` / `ヤブ医者` / `泣き虫` / `同い年` / `仲よし` / `飼い犬` /
`敷地内` / `食糧不足` / `気がかり` / `かかわりあい` / `カネ目`（「カネ目のもの」＝金目のもの）

## 数量表現

- `一部族` → `一` `部族`、`数本` → `数` `本`（助数詞でない普通名詞でも数詞を分離する。
  共通ルール参照）。
- `一八八一年` → `一八八一` `年`。

## 接尾辞

- `ジョースター卿` → `ジョースター`（`卿` は `様` と同様の敬称接尾辞として除外）。
- `父さん` → `父`（`さん` 除外）。

## 接頭辞

- `お礼` → `礼`、`ご婦人` → `婦人`（美化語・敬語接頭辞として外す）。

## 表記ゆれ（本文の表記のまま抽出、正規化しない）

- `だんな` `だんなァ`（旦那）、`あたしゃ`→`あたし`（`ゃ`は「は」の縮約なので外す）、
  `てめー`（てめえ）、`だれ`（誰）、`マヌケー`（マヌケの伸ばし）、`赤んぼ`（赤ん坊の異表記）。

## 保留（要確認）

- P.13「気味の悪い仮面だ ここにいつはいらねェな!」の `いつ` — 文脈上「こいつ」の
  誤植の可能性があるが、本文表記どおり `いつ` として抽出した。原文（1_セリフデータ）側の
  確認が必要な場合はユーザーに要確認。
