# 単語分割ルール（BLEACH）

共通ルールは `2_単語抽出/単語分割ルール_共通.md`。ここには BLEACH 固有の
確定済み判断だけを記録する。同種の語が出たら再質問せずこのとおり処理する。

（1巻1話のユーザー確認で確定）

## 親族呼称・呼びかけ

- `おにいちゃん` `お兄ちゃん` `お父さん` `父さん` `母さん` `親父` `一兄` は
  **1語のまま**抽出する（美化語「お」・接尾辞「さん・ちゃん」を外さない。表記どおり）。
  - `おにいちゃん` と `お兄ちゃん` は別表記として区別して記録する。
- `父親` = 1語 ／ `おまえ` `お前` `お主` `貴様` `てめえ` `てめぇ` `テメー` = 代名詞1語。
- 愛称＋愛称接尾辞は接尾辞を外す（`ナルト君→ナルト` 前例に準拠）:
  `山ちゃん` → `山` ／ `ミッちゃん` `ミッちゃーん` → `ミッ` ／ `トシりん` → `トシ` ／
  `夏梨ちゃん` → `夏梨`
- `小僧` `ガキ` `クソガキ` `糞餓鬼` `餓鬼` `たわけ` `ボケェ` `コノヤロウ` `莫迦者`
  `バカ` = 罵倒語として名詞1語（`クソガキ` `糞餓鬼` `コノヤロウ` `莫迦者` は接頭辞込みで1語）。
  - `バカ` は用法を問わず抽出する（`バカな——` `そんなバカな話` `バカみたい` `バカ言え` すべて `バカ`）。

## 「やつ・者」など

- `やつ` `奴` `者` `輩` `連中` `我々` はすべて名詞として抽出する
  （`というやつ` `する者` のような形式名詞的用法も含めて抽出）。
- `何者` → `何` `者`。

## 固有名詞・呼称（1語のまま）

- 人名は分かち書きでも1語:`朽木ルキア` ／ ルビ付きは `ベース（読み）` で1語:
  `黒崎一護（くろさきいちご）` `夏梨（カリン）` `遊子（ユズ）`
- `死神` `死神（わたし）` = 1語 ／ `死神ゴッコ` → `死神`（`ゴッコ` は接尾辞で外す）
- `虚` `虚（ホロウ）` = 1語 ／ `整` `魂魄` `生者` `死者` = 各1語
- `鬼道` `縛道` `斬魄刀` `霊圧` `霊力` `霊法` `魂葬` `成仏` `除霊` `退治` `呪術` = 各1語
- `尸魂界` `尸魂界（ソウル・ソサエティ）` `ソウル・ソサエティ` = 1語
- `空座町` `空座町（カラクラチョウ）` `軽井沢` = 地名1語
- `男爵陛下（バロンへいか）` `サカナ面（ヅラ）` `塞（サイ）` `外（ほか）` = ルビ形1語
- `黒揚羽` `我が家` `この世` `町医者` `敵前` = 1語
- `ゴーストピクニック` = 1語（作中の企画名）

## 複合語の分割（各1語に分割）

- `超A級霊媒体質` → `超A級` `霊媒` `体質`
- `霊的濃度` → `濃度` ／ `霊的資質` → `資質`（`霊的` はナ形容動詞語幹＝名詞のみモードでは取らない）
- `悪霊退治` → `悪霊` `退治` ／ `不良息子` → `不良` `息子` ／ `男子高校生` → `男子` `高校生`
- `コミュニケーション手段` → `コミュニケーション` `手段` ／ `成功率` → `成功` `率`
- `鉄の団欒` → `鉄` `団欒` ／ `血の制裁` → `血` `制裁` ／ `縛道の一` → `縛道` `一`
- `指令外` → `指令` `外`
- `四重苦` = 1語 ／ `半分` = 1語（`半分の` でも分割しない）

## 数量表現

- `午前二時二十三分` → `午前` `二` `時` `二十三` `分`
  （`午後七時十三分` → `午後` `七` `時` `十三` `分`）
- `何時` → `何` `時` ／ `10倍` → `10` `倍` ／ `一回` → `一` `回` ／ `2階` → `2` `階`
- `2種類` → `2` `種類` ／ `5月限定` → `5` `月` `限定`
- `一つ` → `一` `つ`（数詞と助数詞を分ける）／ `一人` → `一` `人` ／ `二人` → `二` `人`
- `2つ目` = 1語（序数）／ `誰一人` → `誰` `一` `人`

## 接頭辞・美化語

- 複合語として1語: `大正解`（`大` 溶け込み）
- 美化語は外す: `お花見` → `花見` ／ `お供え物` → `供え物` ／ `お願い` → `願い` ／
  `お互い` → `互い`
- `おかわり` = 1語（食卓での定型の一語発話。慣用として残す）

## 形式名詞・その他

- 抽出する時間・場所名詞: `今` `頃` `時` `前` `後` `先` `先程` `先刻` `さっき` `こないだ`
  `このごろ` `最近` `先月` `今回` `毎日` `毎晩` `初夏` ／ `辺り`（場所を指す）
- 取らない: `普段`（＝いつも・副詞的）／ `本来` `一体` `一応` `生憎`（副詞）
- `せい`（所為＝原因・責任）は名詞として抽出する。
- `狙い` `高さ` `動き` `悩み` は名詞化した自立語として抽出する。
- `済み`（`承知済み` 等）は接尾辞相当で除外。
- 感動詞は名詞のみモードでは取らない: `くそ` `畜生` `ちくしょう` `ちくしょうっ` `成程` 等。
