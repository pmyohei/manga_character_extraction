# 単語分割ルール（名探偵コナン）

`2_単語抽出/単語分割ルール_共通.md` を前提に、名探偵コナン固有の確定判断を記録する。

## 複合名詞の分割粒度

**「名詞＋名詞」型の複合語は分割せず1語のまま扱う。**（ユーザー確認済み）

- 例: `高校生探偵` `推理小説` `推理オタク` `日本警察` `拳銃密輸` `空手部` `サッカー部`
  `体操部` `バランス感覚` `段違い平行棒経験者` `世界最高` `都大会` `女主将` `迷宮入り`
  `恋人同士` `バラバラ死体` `運動神経` `救世主` `名探偵` `難事件` `家中` `世界中` `今頃`
- 接頭辞・接尾辞が溶け込んだ複合サ変名詞も1語: `新開発`（新開発する）。
- 接尾語的な `〜ゴッコ` も分割しない: `探偵ゴッコ`。
- 固有名の全名は1語: `工藤新一`。`工藤君`→`工藤`、`新一`単独は`新一`。
  `コナン・ドイル` `シャーロック・ホームズ` は中黒込みで1語。

## 位置・方向の名詞

**`中`（なか）`上`（うえ）`横`（よこ）`後ろ` は、共通ルールの `前`・`後`・`先` と同様に抽出する。**
（ユーザー確認済み。`方`（ほう＝側・方向・相対参照）は共通ルールどおり除外）

- 例: `バッグの中` → `中`、`コースターの上` → `上`、`横には流れない` → `横`

## 「物」の扱い

**具体的な物体・証拠品を指す `物` は名詞として抽出する。**（ユーザー確認済み）

- 例: `こんな物が!!` `バッグに入れた物`（＝凶器の器具）→ `物`
- `残ったものは` など「〜したもの」の形式名詞用法は共通ルールどおり除外。

## 「女の子」「女の人」

**一般語だが「〜の〜」型として `の` を除いて前後を各1語にする。**（ユーザー確認済み）

- `女の子` → `女` `子`、`女の人` → `女` `人`

## 形容動詞語幹の単独言い切り（名詞のみモードでは除外）

共通ルール（`卑怯？` 等）に従い、述語・単独言い切りで形容動詞になっている語は除外する。

- 例: `冷静沈着!!` `可能だ` `無理だ` `変だ` `平気で` `いいかげんにして` `ダメだ`
  `サイテー!!` `大丈夫か` `好都合だ` `マジかよ` `ラッキーで`
- ※ 名詞用法（`〜の` `〜は` `〜を` を伴う）なら抽出: `独特のアザ` → `独特`、
  `必要はない` → `必要`、`大量の睡眠薬` → `大量`、`大粒の涙` → `大粒`。
- ※ `天下一品` `インチキ` `でたらめ` は名詞として扱い抽出する。

## その他の確定判断

- `だいいち`（＝「そのうえ／第一に」の接続詞・副詞用法）は名詞のみモードでは除外。
- `せい`（所為＝原因・ふるまい）は形式名詞的として除外（`〜のせいで` `〜のせい`）。
- `以外` `以上`（`犯人以外` `それ以上`）は名詞として抽出する。
- `友人A` `友人B` … は `友人` と アルファベット記号 `A` `B` … に分ける。
- `みなさん` → 接尾辞 `さん` を外し `みな`。
