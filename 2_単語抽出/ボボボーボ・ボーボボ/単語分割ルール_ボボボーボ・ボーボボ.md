# 単語分割ルール（ボボボーボ・ボーボボ）

`ボボボーボ・ボーボボ` 固有の単語抽出（`2_単語抽出/`）の確定判断。
共通ルールは `2_単語抽出/単語分割ルール_共通.md` を参照。

## 固有名詞・複合語の分割粒度（確定済み）

- **1語のまま扱う**:
  - `ボボボーボ・ボーボボ` / `ボーボボ` / `ボーボボ・ザ・ボーボボ`（表記どおり。中黒を割らない）
  - `マルハーゲ帝国`
  - `毛狩り` / `毛狩り隊`
  - `鼻毛真拳` / `ワキ毛真拳`（拳法名の「〜真拳」）
  - `鼻毛激烈拳` / `鼻毛姫拳` / `搾り鼻毛`（技名）
  - `我が国`
  - `使い手`
  - `丸ボーズ`
  - `アフロ屋`
  - `燃えろボーボボ伝説`（作中ゲームタイトル）
  - `イナフ村`
- **分割する**:
  - `マルハーゲ帝国毛狩り専属部隊` → `マルハーゲ帝国` `毛狩り` `専属` `部隊`
  - `鼻毛真拳奥義` → `鼻毛真拳` `奥義`、`鼻毛真拳究極奥義` → `鼻毛真拳` `究極` `奥義`
  - `ツル・ツルリーナ4世` → `ツル・ツルリーナ` `4` `世`
  - `Gブロック基地` → `G` `ブロック` `基地`
  - `脱出ポット` → `脱出` `ポット`
  - `グッドアイデア` → `グッド` `アイデア`
  - `ゲームソフト` → `ゲーム` `ソフト`
  - `恋愛シミュレーション` → `恋愛` `シミュレーション`
- **「毛の〜」**（毛の自由／毛の王国／毛の平和／毛の未来）は共通ルールの「〜の〜」型に従い
  `毛` と後ろの語を各1語にする。
- **ルビ形式**: `毛魂（バーニング）` は `ベース（読み）` のまま1語。

## 品詞判断（名詞のみモード、確定済み）

過去のユーザー確認で確定。同種の語が出たら再質問せずこのとおり処理する。

- **`うそ` / `うっそー` / `ウソ` / `うそぉ`** — 感嘆的に単独使用されていても名詞として抽出する
  （本文の表記・伸ばしどおり）。
- **`マジ`** — 名詞として抽出する（`マジで?` の場合も助動詞「で」を外して `マジ`）。
- **`OK`** — 名詞として抽出する（`OK!!` の感動詞的な掛け声でも取る）。
- **`いくら`** — 価格・数量をたずねる用法（`これいくら?`）は代名詞として抽出する。
  程度・仮定の副詞用法（`いくらボーボボでも`）は共通ルールどおり除外する。

## 感動詞（名詞のみモードでは除外、確認不要）

`オラー` `しゃー` `くっ` `む` `へー` `ふん` `うん` `おお` `え` `あ` `ん` `な` `ハッハッハ`
`クックック` `フォッフォッフォッフォ` `クッバイ` `わーい` `わー` `スッゲー` `おめでとう`
`はじめまして` `うむ` `さあ` `さらば` `くっそ` 等。
文頭で驚きを表す `なんだ`（`なんだ、また お前か` 等）は共通ルールの疑問形として核 `なん` を抽出する。
