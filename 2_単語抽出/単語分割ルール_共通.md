# 単語分割ルール（共通）

全作品に共通する単語抽出（`2_単語抽出/`）のルール。
**作品固有の語の扱いは `2_単語抽出/<作品名>/単語分割ルール_<作品名>.md` に記録する。**

`1_セリフデータ/` のセリフテキストを形態素解析し、単語単位に分割して出力する作業。
セリフ抽出とは独立した作業で、ユーザーが対象（作品・巻・話）を指定して依頼する。
**目的は単語の出現頻度分析。**

## 入力

- 指定された `1_セリフデータ/<作品名>/<作品名>_<巻数>巻.txt`。
- **指定された巻・話のみを対象にする。** 範囲外・未指定の話には触れない。

## 抽出モード

2つのモードがある。**どちらで抽出するかはユーザーがプロンプトで指示する。**
指示がない場合は「全自立語」モードとして扱う。

- **全自立語モード（既定）**: 下記「抽出ルール」の対象品詞をすべて取り出す。
- **名詞のみモード**: ユーザーが「名詞のみ」と指示した場合。対象品詞を
  **名詞・代名詞・数詞のみ**に限定する（動詞・形容詞・形容動詞・副詞・連体詞・
  接続詞・感動詞は取り出さない）。数量表現の助数詞（人・年・回・級 等）は名詞として残す。
  それ以外の判断（複合名詞の分割粒度、「〜の〜」型の名づけ、接尾辞・接頭辞の扱い、
  ルビ、重複除去しない 等）は全自立語モードと同じ。
  モードによって出力ファイル名が変わる（→「出力」）。

## 抽出ルール

- テキストを構文（形態素）解析し、**自立語**を出現順に1語ずつ取り出す。
  - 対象品詞: 名詞・代名詞・数詞・動詞・形容詞・形容動詞・副詞・連体詞・接続詞・感動詞。
- **抽出対象の文章の表記は絶対に変更しない。** 漢字変換・かな変換・正規化・原形化をしない。
  助詞・助動詞・接尾辞などを外した残りを、本文に出た表記のまま1語として取り出す。
  - 例: 「なんで」の「なん」を「何」に漢字変換しない。「なんで」「なんじゃ」は助詞を外し
    `なん` で抽出する。かな表記の疑問語（`なん` `なに` 等）を `何` にまとめない。
  - 例: カタカナ強調の代名詞（`コレ` `コイツ` 等）も本文どおり（`これ` `こいつ` にしない）。
  - 例: 伸ばし・訛りもそのまま（`お前ェ` `手ェ` `ナルトォ` `バケ狐ェェ` `バ―カ` 等）。
- **抽出対象外**:
  - 行マーカー `■第<話数>話` `■P.<ページ数>`（話の区切りには使うが単語にはしない）。
  - `（セリフなし）`。
  - 記号・強調（`…` `!!` `!!!` `——` `!?` `?` `？` `、` `。` `・` 等）。
  - **助詞・助動詞**（は・が・を・に・へ・と・の・も／た・だ・です・ます・ない 等）。
    頻度分析ではノイズになるため除外する。
- **活用語（動詞・形容詞）は表記どおり**に取り出す。本文に出た活用形のまま（原形化しない）。
  - 例: 「手に入れた」→ `手` `入れ`、「恐くない」→ `恐く`
- **重複は除去しない。** 出現するたびに1語として記録する（頻度分析のため）。
- **ルビ**: `海賊王（ゴールド・ロジャー）` のような括弧付きは、`ベース（読み）` の形のまま
  1語として取り出す（例: `銃（ピストル）`）。括弧内の読みを単独の単語にはしない。
  ルビが付いていない同じ語はそのまま取り出す。
- 複合語・固有名詞の分割粒度、感動詞かオノマトペか、その他**品詞や区切りの判断に迷う語があれば、
  処理を進める前に必ずユーザーに確認する。** ただし本ファイルおよび作品別ルールで
  確定済みの判断は再確認せず、そのまま適用する。

## ルール統一（確定済みの判断）

過去のユーザー確認で確定した方針。同種の語が出たら再質問せずこのとおり処理する。

**複合名詞の分割粒度** — 慣用複合語は1語のまま扱う（構成要素に分割しない）。
具体的な語は作品別ルールに記録する。

**「〜の〜」型の名づけ** — 助詞「の」でつながる名づけは「の」を除いて前後を各1語にする。
- 例: `ゴムゴムの実` → `ゴムゴム` `実`、`悪魔の実` → `悪魔` `実`

**短い発声** — すべて感動詞として抽出する（オノマトペ扱いで除外しない）。
本文の表記どおりに取り出す（`あーあー` `ふーん` `くそオ` 等）。
- 例: `ふん` `はっ` `ほう` `おお` `ん` `へー` `げ` `うわ` `よっしゃ` `がはは` `ちくしょう`
- ※ 名詞のみモードでは感動詞は除外なので取らない。

**「一番」** — 用法を問わず常に名詞として抽出する（副詞用法「一番〜だ／一番〜な」でも取る）。
- 例: `里一番の忍者` → `里` `一番` `忍者`、`一番にがてな術` → `一番` `術`

**数量表現** — 数詞と助数詞を分け、両方をそれぞれ1語として記録する。
- 例: `八百万ベリー` → `八百万` `ベリー`、`56人` → `56` `人`、`10年後` → `10` `年` `後`、
  `2・3回` → `2` `3` `回`、`第一級` → `第一` `級`
- **後続が「人・年・回・級」等の狭義の助数詞でなく普通名詞でも、数詞は常に分離する。**
  （例: `一部族` → `一` `部族`、`数本` → `数` `本`。「数」のような漠然とした数量接頭辞
  （数人・数日 等）も数詞として分離する。）
- **序数（〜代目・〜度目 等、末尾が「目」の順序表現）は数詞と一体で1語**にする
  （例: `三度目`）。ただし称号などで作品別ルールが別途定めている場合はそれに従う。

**接尾辞（達・共・さん・くん・様・卿・め・ら 等の敬称・複数化辞）** — 自立語ではないため除外し、
直前の自立語を1語として記録する。
- 例: `おれ達` → `おれ`、`シャンクスめ` → `シャンクス`、`海賊共` → `海賊`、`お前ら` → `お前`、
  `火影様` → `火影`、`ナルト君` → `ナルト`、`ジョースター卿` → `ジョースター`

**接頭辞（お・ご・大 等の美化語・強調）** — 語に溶け込んでいれば複合語として1語（`大ケガ` `おたずね者`）。
  単なる美化語・敬語接頭辞なら外す（`お酒` → `酒`、`お別れ` → `別れ`、`お願い` → `願い`、
  `お礼` → `礼`、`ご婦人` → `婦人`）。

**補助動詞・助動詞相当** — 除外する。
- 例: `〜てる` `〜ちまう` `〜やがる` `〜たい` `れる`・`られる`（受身）`〜てく` `〜そう`（様態）

**擬態語** — 文中で状態を表す自立語（副詞）として使われていれば抽出する
（名詞のみモードでは副詞なので取らない）。述語になっている擬態語（`ボロボロじゃねーか` 等）は
形容動詞用法として扱い、名詞のみモードでは除外する。
- 例: `びしょびしょ` `ぼーっと` `プカプカ` `ヘラヘラ` `ムカムカ`

**「なんて」「なんか」**（副助詞用法）は除外。
**疑問の「なんで」「なんじゃ」「なんだ」「なんだと」「なにィ」等**は、本文の表記のまま
助詞・助動詞を外した核（`なん` `なに` 等）を1語として取り出す（**`何` に変換しない**）。
漢字で `何` と書かれている場合（`何でも` `何だって` `何なんだ` `何に` 等）は `何` を取り出す。
- **口語の断定 `〜なんだ`／`〜なんだよ`（＝`〜なのだ`）は助動詞相当で除外する。**
  例: `九尾の妖狐なんだよ` `同じなんだよ` `〜するためのものなんだよ` → `何`/`なん` を取らない。
- **言いよどみのフィラー**（`ま、なんだ…` 等）の `なんだ` も除外する。

**形式名詞は除外する。** — `こと` `もの` `とこ` `ところ` `所` `つもり` `場合` `ため` `わけ`
`はず` `まま` `もん` `様（な）` `くせ` `次第` `途端` `挙げ句` `通り` `方（ほう＝側・方向・相対参照）`
`うち（`〜ないうちに` `〜するうちに` 等の時間・範囲を表す文法用法）` 等。
- 共通ルールのこのリストに明記されていない語でも、文法的に形式名詞・準体助詞相当として
  使われていれば同様に除外する（例: `ほど`＝程度（`名のるほどの者` 等）、
  `の`＝準体助詞・こと／もの代用（`そんなの` 等））。
- ※ `〜方（かた＝方法）` は複合語として1語にする（`使い方` `やり方`）。
- ※ 具体的な時間・場所を指す名詞（`時` `頃` `今` `昔` `さっき` `場所` `前` `後` `先` 等）は抽出する。
- ※ `あと`（`あと10歳` `あと2・3回` `あと どれくらい` 等、数量・程度に付く「もう〜」の意）は
  時間名詞 `後` として抽出する（数量表現が続く場合は `あと` と数詞を分ける）。

**形容動詞・形容詞の語幹／活用形は名詞のみモードでは取らない。** — 述語や連用で品詞が
形容動詞・形容詞になっている語は、名詞と同形でも除外する。
- 例: `卑怯？`（単独の言い切り＝形容動詞語幹）、`気持ちよく`（形容詞「気持ちよい」の連用形）、
  `平気で` `静かで` `無事で` `大変` `致命的` `不思議` `充分` 等。
- ※ 明確に名詞用法（`〜を` `〜が` `〜の` を伴う 等）なら抽出する（`気持ちはわかる` の `気持ち`）。

**罵倒語・ののしりの呼びかけは名詞として抽出する。** — `バカ` `バカ者` `バカヤロー` `バカ野郎`
`カス` `ガキ` `野郎` `けち` 等（表記どおり。伸ばし・訛りもそのまま: `バ―カ` `バカヤロ―`）。
接頭辞が溶け込んだものは複合1語（`大バカもの`）。
動詞用法（`バカやった` の `やった`）は動詞なので別。

**サ変名詞**（`封印` `利用` `心配` `説教` `我慢` `分身` `変化` `解放` `復讐` `壊滅` `毛嫌い`
`徹底` 等）は名詞として抽出する（`〜する` の `する` は動詞として別扱い）。

**代名詞は名詞のみモードでも抽出対象**（対象品詞に代名詞・数詞を含む）。
- 例: `オレ` `お前` `あいつ` `こいつ` `てめェー` `わし` `ボク` `君` `自分` `誰` `みんな` `皆`
  `これ` `それ` `あれ` `ここ` `そこ` `こっち` `そっち` `何`。
- `これから` `これまで` のような「代名詞＋助詞」の連語は、代名詞 `これ` を取り出す。

## 出力

- ディレクトリ: `2_単語抽出/<作品名>/`（`<作品名>` は 1_セリフデータ と同じトークン）。
- ファイル名（抽出モードで変わる）:
  - **全自立語モード**: `単語_<作品名>_<巻数>巻.txt`
  - **名詞のみモード**: `単語（名詞のみ）_<作品名>_<巻数>巻.txt`
  - どちらのモードも同じ作品ディレクトリに出力する。既存の他モードのファイルには追記しない。
- **第n話ごと**にまとめる。
  - 話の区切り: `■第<話数>話`
  - その下に単語を出現順で1行1語（`■P.` 等のページマーカーは付けない）。
- 既存ファイルに追記する場合は話番号順を保つ。

例（第1話 P.1 の「富・名声・力 かつてこの世の全てを手に入れた男 海賊王（ゴールド・ロジャー）」から、全自立語モード）:

```
■第1話
富
名声
力
かつて
この世
全て
手
入れ
男
海賊王（ゴールド・ロジャー）
```

## 作業手順

1. ユーザーの指示から抽出モード（全自立語 / 名詞のみ）を確認する（指示なしは全自立語）。
2. 対象作品の `2_単語抽出/<作品名>/単語分割ルール_<作品名>.md` があれば読む。
3. 指定された `1_セリフデータ/<作品名>/<作品名>_<巻数>巻.txt` を Read で開く。
4. 対象の話のセリフ行を形態素解析し、本ファイル・作品別ルール・モードに従って単語を取り出す。
5. 判断に迷う語があれば、先にユーザーへ確認する。確定したら作品別ルールに追記する。
6. モードに対応したファイル名で `2_単語抽出/<作品名>/` に第n話ごとに出力する
   （新規なら作成、既存なら話番号順を保って追記）。
