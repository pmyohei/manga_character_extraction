# 単語分割ルール（ONEPIECE）

共通ルールは `2_単語抽出/単語分割ルール_共通.md`。ここには ONE PIECE 固有の
確定済み判断だけを記録する。同種の語が出たら再質問せずこのとおり処理する。

## 複合名詞（1語のまま扱う）

`海賊王` / `大海賊時代` / `海賊船` / `海賊旗` / `ゴム人間` / `ゴム小僧` / `見世物小屋` / `港村` /
`賞金首` / `世の中` / `目の前` / `この世` / `死に際` / `遊び半分` / `ごきげんナナメ`（状態を表す
複合名詞。`〜だ／な` の述語用法でも名詞として抽出する） / `仲間集め` / `船出日和` / `用なし`

## 罵倒語の複合／分割

- `バカ野郎` `バカヤロー` は定型のののしり語 → 1語のまま。
- `バカ＋一般名詞`（`バカ山賊` `バカ息子` 等）は `バカ` と後続名詞に分割する
  （後続が自立名詞のため。`バカ` は罵倒語として1語で記録）。

## 数量表現

- `八百万ベリー` → `八百万` `ベリー`
- `一件`（`山賊の一件` 等の「例の件」の意）→ `一` `件` に分割。
- `一戦` → `一` `戦`、`一発` → `一` `発`、`一つ` → `一` `つ`（数詞と助数詞を分ける）。

## 「〜の〜」型の名づけ（「の」を除いて前後を各1語）

- `ゴムゴムの実` → `ゴムゴム` `実`
- `悪魔の実` → `悪魔` `実`
- `近海の主` → `近海` `主`
- `魚屋のおっちゃん` → `魚屋` `おっちゃん`

## 接尾辞（除外し直前の自立語を記録）

- `おれ達` → `おれ`、`シャンクスめ` → `シャンクス`、`海賊共` → `海賊`、`お前ら` → `お前`

## 接頭辞

- 複合語として1語: `大ケガ` `おたずね者`
- 美化語は外す: `お酒` → `酒`、`お別れ` → `別れ`

## 短い発声（感動詞として抽出。名詞のみモードでは取らない）

`ふん` `はっ` `ほう` `おお` `ん` `へー` `げ` `うわ` `にひ` `よっしゃ` `がはは` `ちくしょう`
`あーあー` `おうおう` `ふーん` `くそオ` `くそ` `畜生` `畜生お`（罵倒の叫び＝感動詞扱い）
